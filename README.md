# 黑沙助手 BDH

黑沙助手 BDH 是面向《黑色沙漠》PC 台港澳與國服玩家的免費工具站，提供漁獲行情比較、魚種圖鑑和行情截圖分享。

## 開始使用

- [開啟黑沙助手 BDH](https://bdh-doa.pages.dev/)
- [简体中文入口](https://bdh-doa.pages.dev/?region=CN)
- [台服魚種圖鑑](https://bdh-doa.pages.dev/fish/)
- [国服鱼种图鉴](https://bdh-doa.pages.dev/cn/fish/)
- [使用說明](https://bdh-doa.pages.dev/guide/)
- [简体使用说明](https://bdh-doa.pages.dev/cn/guide/)

先選擇遊戲地區，再查看對應的魚種和行情。需要比較魚價時，可在工具內選擇魚種、分流與貿易地點。

行情來自玩家上報，查看時請留意採集時間；資料不代表遊戲內即時價格。圖鑑名稱按地區區分，不代表該魚目前一定能取得或販售。

本站為玩家工具，與遊戲官方無隸屬關係。資料處理與保存期限見[隱私說明](https://bdh-doa.pages.dev/privacy/)。
